## 🌐 资料站点与推荐项目

除了本仓库，我还整理了一些个人比较推荐站点，大家有时间也可以去逛逛：

### 核心站点
- **[BIT share](https://portal.site-2.teclab.org.cn/?id=site2-bitshare-app)**
  目前 BIT 开源资源的 NO.1，东西非常齐全。电子版教材、往年题、代码、MOOC 答案应有尽有，且更新非常快。

- **[BIT101 Drive](https://onedrive.bit101.cn/zh-CN/)**
  这里主要存放往年题（多为 2024 年之前的试卷）。期末周想要大量刷题的同学可以在这里面“淘”一些老试卷。

### 其他资源
- **[若干 BIT-CS 学习资料 GitHub 仓库](https://bit101.cn/gallery/5850)**
  汇集了多位学长学姐开源的资料，大家可以按需查找。
- **[信科通关指南](https://old.ovideros.site/p/%E4%BF%A1%E7%A7%91%E5%A4%A7%E4%B8%80%E9%80%9A%E5%85%B3%E6%8C%87%E5%8D%97/)**
  o 佬的信科大一通关指南，不多说，神中神，常看常新。
