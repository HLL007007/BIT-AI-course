# 北京理工大学  人工智能  2025级本科生学习资料

## 写在前面：

笔者认为自己是一个信息检索能力较强的人（也有可能是认识的学长学姐比较多），在学习资料整理方面有一点点心得，并且我也愿意将这些分享给大家，之后的几个学期我也会在这里继续上传我的学习资料以及自己总结的一些的笔记。

## 资料站点以及推荐的项目：
我这里只保留了一些我自己用起来顺手的资料，大家有时间也可以去下面的站点逛一逛：
- [**BIT share**](https://www.bitshare.com.cn):
  目前BIT开源的NO.1，东西非常齐全，电子版教材、往年题、代码、mooc答案应有尽有，而且很新
- [**BIT101 Drive**](https://onedrive.bit101.cn/zh-CN/):
  这里主要是一些往年题，大概都是2024年之前的试卷，期末周有同学想要刷题的可以这个里面淘一些试卷
- [**若干 BIT-CS 学习资料 GitHub 仓库**](https://bit101.cn/gallery/5850):
  这里是一些学长学姐开源的资料，大家也可以在里面逛逛看看有没有自己需要的
- [**信科通关指南**](https://old.ovideros.site/p/%E4%BF%A1%E7%A7%91%E5%A4%A7%E4%B8%80%E9%80%9A%E5%85%B3%E6%8C%87%E5%8D%97/):
  o佬的信科大一通关指南，不多说，神中神,常看常新
